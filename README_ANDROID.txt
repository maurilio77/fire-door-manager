FIRE DOOR MANAGER V5 - PROGETTO APP ANDROID

Progetto Android completo che incorpora la versione V5 in una WebView a schermo intero.
L'app si avvia dalla propria icona FDM. Le risorse dell'icona sono gia' incluse.

Il progetto puo' essere compilato con Android Studio oppure tramite GitHub Actions
usando il workflow presente in .github/workflows/build-apk.yml.

Output APK debug: app/build/outputs/apk/debug/app-debug.apk

I dati della V5 restano nella memoria locale del dispositivo. Eseguire backup JSON
prima di disinstallare l'app o cancellarne i dati.
La sincronizzazione automatica multi-dispositivo non e' inclusa in questa versione.
